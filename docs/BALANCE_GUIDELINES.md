# BALANCE_GUIDELINES.md

# Cyclical TCG — Balance Guidelines

# Purpose

This document defines:

* gameplay pacing philosophy
* balance targets
* card efficiency expectations
* resource pacing
* combat philosophy
* interaction philosophy

This document exists to:

* maintain long-term gameplay health
* guide future card creation
* prevent power creep
* preserve core game identity

---

# Core Gameplay Philosophy

The game is designed around:

* board-centric gameplay
* tactical positioning
* gradual escalation
* low randomness
* meaningful combat
* controlled resource growth

The game intentionally avoids:

* excessive burst damage
* infinite scaling
* heavy draw engines
* overly explosive combo turns
* excessive reaction chains

---

# Average Match Length

---

# Average Turn Count

Target:


# Match Feel

Matches should feel:

* tactical
* interactive
* readable
* steadily escalating

NOT:

* instantly snowballed
* solitaire-like
* combo-only
* excessively defensive

# Deck Size Philosophy

Default deck size:

```txt id="a8k3de"
30 cards
```

Default copy limit:

```txt id="m3q2vz"
2 copies per card
```

# Design Philosophy

30-card decks:

* improve consistency
* support revolve pacing
* reduce excessive variance

2-copy limits:

* preserve deck identity
* reduce repetitive gameplay
* encourage broader deckbuilding

---

# Resource Philosophy

# Infuse System

The game uses:

* temporary resources only

Resources are generated through:

# Infuse

Unused resources:

* disappear at end of turn

---

# Design Goals

The resource system should:

* reward planning
* create meaningful tradeoffs
* prevent excessive mana banking

---

# Late Game Philosophy

Late-game cards should:

# require setup

Players should NOT:

* consistently play huge threats early

---

# Primed Philosophy

Primed exists to:

* reward cyclical planning
* create delayed payoff
* reinforce Revolve gameplay

Large threats should often require:

* repeated Infusing
* Revolves
* setup turns

---

```txt id="d8x2tu"
10 cost
```

# Cost Expectations

## 1–2 Cost

* utility
* setup
* tempo tools
* early aggression

---

## 3–5 Cost

* core gameplay range
* efficient Units
* interaction tools

Most gameplay should happen here.

---

## 6–8 Cost

* high-impact threats
* major swing cards
* strong payoff Units

Should require:

* commitment
* timing
* setup

---

## 9–10 Cost

* game-defining threats
* archetype finishers
* major combo payoff

Should be:

* rare
* risky
* difficult to deploy efficiently

---

# Board-Centric Philosophy

The battlefield should matter:

# heavily

Winning should usually involve:

* Units
* combat
* positioning
* lane pressure

---

# Combat Philosophy

Combat should:

* create attrition
* generate tension
* reward positioning

Persistent damage reinforces:

* gradual battlefield deterioration

---

# Lane Philosophy

Lane positioning should:

* matter constantly

Players should consider:

* future attacks
* Guard placement
* Overkill routing
* combat sequencing

---

# Aggro Philosophy

Aggressive decks:

* should be viable
* should pressure efficiently

BUT:

* should not consistently end games too early

Target:

```txt id="z4n2px"
Aggro wins around turns 6–9
```

NOT:

```txt id="s2a9wt"
Turns 3–4
```

---

# Midrange Philosophy

Midrange should:

* be the baseline gameplay style

Midrange decks should:

* leverage positioning
* trade efficiently
* generate steady pressure

---

# Control Philosophy

Control decks:

* should exist
* should rely on tactical stabilization

Control should NOT:

* invalidate combat
* ignore the battlefield entirely

---

# Combo Philosophy

Combo decks:

* are allowed
* may have alternate win conditions

However:

* combos should require setup
* combos should remain interactable
* combos should rarely win suddenly from empty board states

---

# Alternate Win Conditions

Alternate win conditions are allowed.

Examples:

* fulfilling conditions
* delayed objectives
* unique archetype victories

These should be:

* rare
* difficult
* telegraphed
* interactable

---

# Draw Philosophy

# Card draw should remain limited

The game already contains:

* strong natural card flow
* end-turn redraw systems

Therefore:

* raw draw is dangerous

---

# Design Goals

Card draw should be:

* expensive
* conditional
* limited

---

# Preferred Alternatives

The game should prefer:

* filtering
* selection
* setup
* conditional generation

over:

* large raw draw effects

---

# Dangerous Draw Effects

The following are considered:

# high-risk mechanics

* mass draw
* cheap draw
* repeatable draw engines
* unconditional draw loops

These should remain:

* rare
* expensive
* carefully tested

---

# Removal Philosophy

# Damage-based removal is primary

The game prefers:

* combat interaction
* damage pressure
* gradual attrition

over:

* unconditional destruction

---

# Hard Removal Philosophy

Hard removal should:

* exist
* remain expensive
* remain limited

Hard removal should NOT:

* dominate gameplay
* invalidate Units

---

# Tempo Removal

Bounce effects:

* are allowed

However:

* they should remain tempo-oriented
* not permanently efficient answers

---

# Silence Philosophy

Silence should:

* counter synergy
* answer scaling
* disrupt engines

Silence should NOT:

* become universal removal

---

# AoE Philosophy

Board wipes exist:

* sparingly

AoE should be:

* expensive
* slower
* weaker than single-target efficiency

---

# Design Philosophy

The game wants:

# Units to stay relevant

Excessive AoE would:

* reduce board importance
* weaken positional gameplay

---

# Healing Philosophy

Healing should:

* exist carefully
* remain weaker than damage pressure

---

# Design Goals

Healing should:

* extend survival slightly
* reward tactical timing

Healing should NOT:

* create endless stall loops
* fully negate combat pressure

---

# Lifesteal Philosophy

Lifesteal:

* should remain moderate
* should scale carefully

Large Lifesteal swings:

* are dangerous in persistent damage systems

---

# Token Philosophy

Tokens are intended for:

* temporary pressure
* swarming
* sacrifice strategies

Tokens should:

* create tempo
* not generate excessive recursion value

Tokens vanish when leaving the battlefield.

---

# Spell Philosophy

Spells should:

* support Units
* create tactical decisions
* reinforce positioning

Spells should NOT:

* dominate gameplay completely

---

# Spell Damage Philosophy

Direct damage exists:

* sparingly

Burn-heavy gameplay should:

* remain limited

because:

* persistent damage already increases pressure naturally

---

# Snowball Prevention Philosophy

The game should actively avoid:

* irreversible early leads

Important balancing considerations:

* direct attack pressure
* Overkill damage
* Dash aggression
* lane collapse

---

# Defensive Recovery Philosophy

Players should have:

* stabilization opportunities
* comeback potential

without:

* excessive reset mechanics

---

# Randomness Philosophy

The game prioritizes:

# low randomness

Random generation should remain:

* minimal
* controlled
* readable

Avoid:

* chaotic outcomes
* excessive RNG targeting
* casino-style effects

---

# Skill Expression Philosophy

The game rewards:

* positioning
* sequencing
* resource planning
* timing
* lane management
* long-term setup

The game should avoid:

* excessive hidden information
* reaction-speed gameplay
* random blowouts

---

# Power Creep Philosophy

Future sets should:

* expand options
* expand archetypes

NOT:

* strictly replace older cards

---

# Eternal Format Philosophy

The game currently targets:

# eternal format support

This means:

* old cards remain legal
* long-term balance matters heavily

Future card design should:

* avoid excessive scaling
* avoid unavoidable win engines
* avoid oppressive efficiency spikes

---

# Keyword Balance Philosophy

Keywords should:

* remain readable
* avoid excessive stacking

Individual cards should NOT:

* contain too many mechanics simultaneously

Recommended:

```txt id="v4n2yk"
1–3 keywords per card maximum
```

---

# Complexity Philosophy

Complexity should come from:

* gameplay decisions
* positioning
* sequencing

NOT:

* unreadable card text
* overly nested interactions

---

# Competitive Integrity Philosophy

The game should prioritize:

* clarity
* fairness
* deterministic outcomes

Players should usually understand:

* why they lost
* what decisions mattered

---

# Future Balance Philosophy

When balancing cards:

* preserve archetype identity
* avoid homogenization
* maintain strategic diversity

The game should support:

* aggro
* midrange
* control
* combo
* alternate-win archetypes

without:

* any single strategy dominating permanently

---

# Final Design Philosophy

The game's balance identity is:

```txt id="y2n4wp"
Board-centric tactical gameplay
with cyclical resource progression
and controlled strategic escalation
```

Every future card should reinforce:

* meaningful combat
* lane interaction
* resource planning
* positional strategy
